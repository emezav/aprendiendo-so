Descripcion general
===================

En este proyecto se introduce una biblioteca minima de usuario para facilitar
la escritura de programas sobre las llamadas al sistema del kernel.

Objetivo
--------

Al finalizar esta etapa, se debe poder construir pequenos programas
de usuario sin escribir todas las invocaciones al kernel de forma manual.

Que se aprende aqui
-------------------

Esta etapa sirve para estudiar:

- wrappers de llamadas al sistema
- runtime minimo de usuario
- organizacion basica de programas y bibliotecas
- separacion entre codigo de aplicacion y detalles de bajo nivel
- primeros programas de usuario escritos en C

Relacion con la siguiente etapa
-------------------------------

Con una libc minima disponible, la siguiente etapa puede concentrarse en abrir
una shell de usuario mas comoda y expresiva.
