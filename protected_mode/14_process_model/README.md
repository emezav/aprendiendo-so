Descripcion general
===================

En este proyecto se evalua si la serie necesita crecer hacia un modelo de
procesos mas completo.

Objetivo
--------

Esta etapa no busca ser necesariamente inmediata. Su sentido es revisar, con la
experiencia acumulada de las etapas anteriores, si hace falta introducir:

- multitarea mas rica
- procesos mejor aislados
- nuevas politicas de planificacion

Que se aprende aqui
-------------------

La idea es llegar a este punto con un sistema capaz de:

- leer disco real
- ejecutar programas de usuario
- usar shell y utilidades basicas

Y solo entonces decidir si conviene crecer hacia mecanismos mas complejos.
